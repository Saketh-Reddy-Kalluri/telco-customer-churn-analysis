# Customer Attrition Analysis and Churn Prediction

## Project Overview
This project analyses customer churn using the Telco Customer Churn dataset and R programming. The objective is to understand the factors associated with customer attrition and build a Logistic Regression model to predict which customers are likely to leave.

## Objectives
- Explore and clean customer data.
- Analyse the relationship between customer attributes and churn.
- Visualise customer behaviour using graphs.
- Build a Logistic Regression model to estimate churn probability.
- Evaluate model performance using classification metrics and an ROC curve.

## Tools and Technologies
- R programming
- RStudio
- Statistical hypothesis testing
- Data visualisation
- Logistic Regression

## Methodology
1. Data loading and inspection.
2. Missing-value checks and preprocessing.
3. Churn distribution analysis.
4. Chi-square tests, t-tests and correlation analysis.
5. Data visualisation using bar charts, boxplots and scatterplots.
6. Train-test split using an 80:20 ratio.
7. Logistic Regression modelling.
8. Model evaluation using a confusion matrix, accuracy, sensitivity, specificity, precision and AUC.

## Predictors Used
- Tenure
- Monthly charges
- Contract
- Internet service
- Tech support
- Online security
- Payment method

## Project Files
- `customer_attrition.R` — R source code.
- `Telco-Customer-Churn.csv` — dataset, if included and permitted for redistribution.

## How to Run
1. Install R and RStudio.
2. Open the R script in RStudio.
3. Place the CSV file in the same folder as the script, if using the relative file path.
4. Run the script from beginning to end.

The script produces statistical test outputs, nine exploratory graphs, a Logistic Regression model, classification metrics and an ROC curve with AUC. Numerical results should be added here after reviewing the actual model output.
